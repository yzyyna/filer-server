01

项目背景

1.1 业务背景

公司作为独立 BU 承接集团配套业务，核心产品包括：

  • 发电机组物联网监控系统：采集发电机组实时遥测、告警、状态
  • 云平台：数据汇聚、远程监控、运维管理
  • 运维服务：现场巡检、远程支持

1#主电站本期共部署 26 台 Easergy MiCOM P3 系列继电保护装置，覆盖：

设备类型数量装置型号典型功能
发电机保护8P3G3050/51、50N/51N、27、59、49、81U
主变保护2P3T3287T 差动、50/51、27、49、81U
母联保护2P3U3050/51、50N/51N、79、49、27、86
进线保护4P3L3050/51、50N/51N、67、79、49、27
馈线保护6P3U3050/51、50N/51N、79、49、27、86
联络保护2P3U3050/51、50N/51N、79、49、27、86
所用变保护2P3T3287T 差动、50/51、27、49、81U

1.2 痛点

作为发电厂强电磁干扰场景下的关键监控页面，业务部门反馈的痛点：

  1. 信息密度低：原有 V1 风格主页无法在一屏内展示 26 台设备
  2. 告警淹没：告警信息没有轮播和分类，重要告警容易被忽略
  3. 数据不准：点表里没有的字段（如温度 T、谐波 THD、序分量 I1/I2、3U0）被错误展示
  4. 操作风险：遥控操作无二次确认，存在误操作风险
  5. 时间筛选不灵活：固定时段（24H/7D）不能满足事故追溯需要

1.3 目标

  • 26 台继保一屏完整展示，不需要滚动
  • 单台详情页信息层次清晰：路径 → 主体信息 → 遥测 → 遥信 → 遥控 → 告警
  • 严格按点表数据展示，不自由发挥添加字段
  • 工业级深色科技感，适合强电磁干扰环境

4.1 主页（26 台集中监控页面）

4.1.1 顶部栏（功能区）

元素行为

4.1.2 设备网格

  • 6 列自适应，gap 6px
  • 5 行卡片，每张卡片铺满容器（不固定高度）
  • 26 台一屏完整显示

r5Ua / Ub / Uc（V）高度 28px，3 列，v 11px，柱条从下往上

4.1.4 告警轮播（顶栏内右）

  • 设备信息：#编号 + 设备名（不重复显示位置）
  • 事件代码 + 含义（同行排列）
  • 时间
  • 「查看全部」按钮 → 弹出活跃告警列表
  • 单击条目跳转单台详情

4.2 单台继保详情页

4.2.1 路径条

集中监控 / 1#主电站 / #01 1#发电机保护 [P3G30]   [返回] [关闭]

4.2.2 主体信息（4 列）

设备名称安装位置所属电站当前状态
#01 + 1#发电机保护 + P3G30 主厂房 A 段 1#主电站 在线 / 告警 / 严重 / 离线
当前状态保持显示状态色徽章（不删除状态信息）

4.2.3 ① 遥测数据

  • 第 1 行（6 列 P-block）：P（kW，priority）/ Q（kvar）/ S（kVA）/ PF / f（Hz）/ U0（V）
    • v 上 k 下布局
    • 单位字号 = 值字号（一致）
    • priority 字号 26px，其余 22px
  • 第 2 行（6 列 phase）：三相电压（Ua Ub Uc，V）+ 三相电流（Ia Ib Ic，A）
    • 「三相电压」标题在 Ua 正上方
    • 「三相电流」标题在 Ia 正上方
    • 柱条从下往上，按值归一化

4.2.4 ② 遥信状态

  • 开入 1-16（寄存器 402007）8 列网格
  • 开入 17-32（寄存器 402008）8 列网格
  • 开出 1-16（寄存器 402049）8 列网格
  • 每项：左侧 DI/DO 编号 + 圆点状态，右侧 0/1 值
  • 文字字号 13px，字重 600（明显）

4.2.5 ③ 遥控 + 实时告警（同行）

左：遥控操作

  • 6 个 Obj 卡片，3 列布局
  • 每 Obj 卡片：分闸/合闸两个按钮
  • 点击 → 弹出防误操作二次确认弹窗
  • 标题栏右侧放「控制记录」按钮

右：实时告警事件

  • 单行紧凑（ind + 设备信息 + 等级 chip + 事件代码 + 含义 + 时间）
  • 标题栏右侧放「历史事件」按钮
  • max-height 自适应，超出滚动

4.2.6 弹窗统一规范

弹窗内容时间选择器
历史事件设备基础信息 + 时间筛选 + 类型筛选 + 事件列表起止时间 + 预设（近 1H/24H/7D/30D/全部）+ 查询按钮
历史曲线设备基础信息 + 参数 chips + 时间筛选 + ECharts 曲线起止时间 + 预设 + 查询按钮
控制记录设备基础信息 + 时间筛选 + 对象筛选 + 记录列表起止时间 + 预设 + 查询按钮
防误操作设备 + 操作 + 寄存器 + 当前状态 + 复选框 + 确认/取消--
弹窗样式：浏览器居中显示，遮罩 rgba(2,6,18,.5)，不模糊（backdrop-filter: blur 不使用）。设备基础信息固定在弹窗头部下方。

4.2.7 控制记录

  • 表头：时间 / 操作人 / 对象 / 操作（4 列）
  • 删除「结果」列（点表无此字段）
  • 删除「寄存器详情」列（点表无此字段）
  • 操作人字段用当前登录用户占位（点表无此字段）

06

交互规则

6.1 状态判定

状态值说明
NORMAL'normal'通讯正常 + 无告警
WARN'warn'一般告警
ALARM'alarm'严重告警
OFFLINE'offline'通讯中断

6.2 告警等级

等级颜色用途
critred保护动作、严重跳闸
warnamber越限告警
okgreen保护返回

6.3 操作确认（防误操作）

  • 遥控按钮点击后必须弹窗二次确认
  • 弹窗包含：设备信息、操作、寄存器、当前状态、操作时间
  • 必须勾选「我已核对设备状态、远动条件和现场安全，确认执行此操作」才能执行
  • 不强制输入账号密码二次确认（避免登录态切走）

6.4 排序与筛选

  • 主页排序：localStorage 持久化（key: relay_sort_${stationId}）
  • 5 状态筛选：单选互斥
  • 电站切换：重置排序为默认

6.5 告警轮播

  • 3 秒切换一条
  • 单条告警宽度自适应（scrollWidth + 40px）
  • 单击条目跳转单台详情

验收标准

9.1 主页验收

  • 26 台设备一屏完整显示，不滚动
  • 5 状态筛选正确（全部/在线/告警/严重/离线）

  • 活跃告警列表弹窗显示设备信息
  • 状态 pill 点击弹浮窗

9.2 详情页验收

  • 路径条显示位置 + 设备 + 型号
  • 主体信息 4 列：设备名/位置/电站/当前状态
  • 9 参数遥测显示 17 项中实际采集的项
  • 32+16 遥信按位展开
  • 6 Obj 遥控有分闸/合闸按钮
