功能路径：数据查询 → 报表查询 → 资产库存使用表

1. 功能说明

资产库存使用表是「数据查询 - 报表查询」下的库存台账查询页，用于按条件查询电站现场物资（消耗品 / 备件）的出入库记录，查看库存与消耗的数量、金额，并导出结果。

本页只做查询、统计、导出；台账的录入与修改在其他环节完成，本页数据只读。

2. 页面结构

自上而下五块：

区域 内容
页面标题 资产库存使用表
筛选条件区 6 个筛选条件 + 重置 / 查询 / 导出 按钮
统计栏 在库数量 / 出库数量 / 总数量 / 总价格
明细表 11 列；序号按物资条目合并跨行
分页 按物资条目分页，每页 5 / 10 / 20 条目可选

3. 筛选条件

条件 控件 默认值 说明
仓库 下拉 全部 选项取自台账实际值
名称 下拉 全部 同上
类别 下拉 全部 同上
库存状态 下拉 全部 只有「在库」「已出库」两种
所属电站 下拉 全部 同上
出入库时间 起止区间（精确到分钟） 当月 1 日 00:00 ~ 当天 23:59 在库 = 最新入库时间，已出库 = 最新出库时间
  • 点击「查询」或按回车生效。
  • 开始时间晚于结束时间时不执行查询，提示「开始时间不能晚于结束时间」。
  • 「重置」把全部条件恢复默认，页码回到第 1 页。

4. 统计栏

指标 口径
在库数量 筛选结果中状态为「在库」的数量之和
出库数量 筛选结果中状态为「已出库」的数量之和
总数量 在库数量 + 出库数量
总价格 筛选结果中 数量 × 单价(元) 之和，保留 2 位小数

四项随筛选结果实时重算，按记录累加，不按名称去重。

5. 明细表

5.1 列定义

列 说明
序号 按物资条目合并，跨该条目的全部状态行
类别 资产 / 备件 / 油品 / 耗材
名称 物资名称
所属电站 电站编号，如 50123-1#
规格型号 规格描述
编号 物资编号
库存状态 只有「在库」「已出库」两种
数量 一律整数，不出现小数位
单位 吨 / 桶 / 只 / 条 等
单价(元) 保留 2 位小数
出入库时间 YYYY-MM-DD HH:mm

表头「出入库时间」带问号图标，鼠标移入显示浮层：「在库的表示最新入库时间，已出库的表示最新出库时间」。

实现约束：必须用自定义浮层（JS 定位 + div）。浏览器原生 title 气泡悬停延迟过长，评审时看不到，等同于没写。

5.2 记录识别规则（取数口径）

  • 识别字段：类别、所属电站、库存状态、单价(元)。
  • 识别字段中任一项不同，即为一条独立记录，即使名称相同也不合并。
  • 条目级 key：类别 | 名称 | 所属电站 | 规格型号 | 编号 | 单价(元)。
  • 同一条目下的「在库」「已出库」分行展示，序号按条目合并（同一物资共用一个序号）。
  • 该规则只在后台取数层生效，页面上不做任何标注。

6. 操作

按钮 行为
查询 按当前条件重算统计与列表，页码回到第 1 页
重置 下拉全部恢复「全部」，时间恢复默认区间，页码回到第 1 页
导出 导出当前筛选结果全量（非当前页）；CSV 格式、UTF-8 BOM 编码（Excel 直接打开不乱码）；文件名 资产库存使用表_YYYYMMDD.csv；含 11 列表头

7. 边界与待确认

7.1 边界

  • 筛选无结果：显示空态提示、隐藏表格、分页显示「共 0 个条目」。
  • 表格固定表头、横向可滚动；打印时隐藏筛选区与操作按钮，保留完整表头。

7.2 待确认

  • 总数量 / 总价格跨单位（吨 / 桶 / 只 / 条）合计是否有意义，是否改为按单位拆分或按金额合计。
  • 序号按物资条目合并（同一物资的在库 / 已出库共用一个序号）是否符合对账口径。
  • 出入库单据由哪个系统登记，是否要求与本页同系统闭环。
  • 是否需要按「客户 - 电站」做数据权限隔离。
  • 单价是否随时间变动，台账是否需留存价格生效区间。
  • 出入库流水保留多久。

自检

  • 功能说明讲清了页面做什么、在哪、边界在哪
  • 字段与口径写到可直接开发的粒度（筛选、统计、11 列、识别规则）
  • 待确认项已列出
  • 无业务线 / 商业化叙述
