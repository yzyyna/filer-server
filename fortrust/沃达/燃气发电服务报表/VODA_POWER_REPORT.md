## 1. 业务背景

沃达在油田井队现场部署燃气发电撬为钻井作业供电。现场人员每日按**可配置班次**（默认 8:00 / 14:00 / 20:00 三班）人工抄表，录入各电表/流量计读数，系统按 Excel 同口径自动计算用气量、用电量、累计值与**发电率**（每方气发电量，kW·h/m³N），用于发电服务效果考核。

- **电站即井队**：一个电站对应一个井队，命名固定为【井队号+电站】（如 50525电站 ↔ 井队号 50525）。
- 同一电站下井位随钻井进度推进更换，但系统**不维护**井别/井类型/设计井深/井位号（报表头留空）。

### 1.1 术语

| 术语 | 说明 |
|---|---|
| 电站（井队） | 报表主体，命名【井队号+电站】，编号即井队号 |
| 发电撬 | 现场发电撬机组，**每个电站 N 台，由平台数据初始化决定**（非固定 2 台），每台撬配 1 块电表（KW·h） |
| 固定表 | 每电站固定 3 块：流量计（沃达）m³N、电表（井队）KW·h、流量计（井队）m³N |
| 机组 | 平台为电站初始化的发电机组设备（如 `24031-1发电机组`），用于录入时勾选在发机组；报表侧**无需配置**，直接引用平台数据 |
| 基准值 | 每块电表的基线配置 = **初始读数 + 变比**，管理员录入（对应 Excel 首录行硬编码常量）；变比默认 1，井队电表样例 3960，**仅作用于电表（井队）** |
| 班次 | 每日抄表时间点，**可配置**（默认 8:00 / 14:00 / 20:00 三班）；当月记录数 = 当月天数 × 班次数 |
| 发电率 | 用电量 ÷ 用气量（kW·h/m³N）；考核阈值不在系统界面展示 |

## 2. 功能需求

### 2.1 电站（井队）初始化与配置（管理员）

**权限：「本人不改专人改」——仅管理员/专人可编辑，填报人只读。**

配置项：

| 配置 | 字段 |
|---|---|
| 基本信息 | 井队号（电站编号）、电站名【井队号+电站】、**井别、井类型、设计井深（米）、井位号**、报表起始月、**班次时间**（可配置，默认 8:00 / 14:00 / 20:00）、状态 |
| 发电撬列表（动态 N 条） | 撬名称（如 VC1000220003撬）、电表基准值（初始读数 KW·h + 变比，默认 1）、排序 |
| 固定表基准值 | 流量计（沃达）、电表（井队）、流量计（井队）各 1 项基准值（初始读数 + 变比，默认 1） |
| 井队电表变比 | 样例 3960（属于电表（井队）的基准值属性），仅作用于井队电表相关计算列 |

规则：
- 撬/机组随平台数据初始化生成，支持后续**新增**（新增撬须录入基准值，历史数据保留）；**不允许删除**已有记录引用的撬/机组（默认口径，待确认 §8.3）。**机组清单不在报表侧配置**，直接取自平台电站下机组设备数据。
- **井别、井类型、设计井深（米）、井位号由电站信息维护**（管理员可改，随钻井进度更新），报表头信息行自动带出；原口径「留空不维护」作废。
- 变比/初始值修改须谨慎：已落库的历史计算快照不回溯重算（见 §3.4），仅影响其后新录入数据。

### 2.2 App 端抄表录入（fortrust-app-h5，工作台「抄表」）

- **入口**：App **工作台新增「抄表」**图标（菜单权限控制）。
- **电站选择**：进入后选择电站，**列表仅展示当前用户绑定的电站**（一人多站可切换，单站直进）。
- **首页 = 当天待填**：默认展示**当天**各班次（按电站配置时间点生成骨架），已填/未填状态，未填可直接录入。
- **历史查看**：历史按钮切换，可按**日 / 月**两个维度查看已填数据（日视图=当日班次明细，月视图=当月班次骨架与完成进度）。
- **在发机组**：后台查询机组运行记录，**返回所有机组并带「已发电」标志**（运行中的机组标记已发电），前端据此展示/默认勾选。
- **录入字段**：

| 字段 | 形态 |
|---|---|
| 值班人 | **自动取当前登录人**，无需填写、不可编辑 |
| 工况 | **字典**（系统数据字典维护，字典类型如 `voda_work_condition`；初始清单 = 原表 Excel 出现值拆分单项并归并错别字，见 §8.5；一格可多工况如「等待下钻，场地维修」，多选拼接展示，见 §8.7） |
| 井深 | 数字（m） |
| 撬电表读数 ×N | 数字（KW·h），按电站动态渲染 |
| 流量计（沃达）读数 | 数字（m³N） |
| 电表（井队）读数 | 数字（KW·h） |
| 流量计（井队）读数 | 数字（m³N） |
| 在发机组 | **机组多选**（勾选当班在发机组；机组为平台电站下设备数据，无需配置） |
| 备注 | **自动生成**：由所选机组名截取「发电机组」后缀拼接（`24031-1发电机组` → `24031-1`），多台以「、」连接（如 `24031-1、24031-2`），不可手填机组名 |

- 保存时服务端按 §3 口径计算并落库计算快照；漏报班次留空，计算跳至上一条有效记录（与 Excel 行为一致）。
- 已提交记录支持修改（权限内）；**后台记录修改人与修改时间**（审计字段，可追溯；导出不含）。

### 2.3 报表基础信息（初始值）配置

管理员在电站配置中维护各表基准值，共 **N + 3 块表**（N 个撬电表 + 井队电表 + 2 块气表）：

| 表 | 初始值 | 配置位置 |
|---|---|---|
| 撬电表 ×N | 开始时的电表读数（**可编辑**） | 电站配置页 |
| 电表（井队） | 初始读数 + 变比（3960） | 电站配置页 |
| 流量计（井队）气表 | 初始读数 | **气表菜单**填写 |
| 流量计（沃达）气表 | 初始读数 | **气表菜单**填写 |

- 气表共 **2 块**：井队气表（流量计-井队）与沃达气表（流量计-沃达），其初始值在平台的**气表菜单**中填写，报表侧读取展示、不在电站配置页重复维护。
- 撬电表初始读数（报表基础信息中）支持修改，历史月计算快照不回溯（§3.4）。

### 2.4 报表查询 — 发电服务报表（PC，管理员菜单）

- 报表查询模块下新增**「发电服务报表」**功能，菜单权限仅授予**管理员**。
- 进入默认展示**当前月**；月度切换、明细、合计、累计总合计、核对行等见 §2.5。
- **自定义表头**：新增弹窗，可将各列表头由「原名称」改为「自定义名称」（仅改展示文本，不改字段口径）；修改后对所有有权限用户生效，可恢复默认。

### 2.5 PC 端报表（iot-web，电站下）

- 入口：电站（井队）节点下的「燃气发电服务报表」，**菜单权限控制显隐**。
- **月度切换**查看明细，表格还原 Excel 版式（双行表头、列见 §3.1）。
- 底部三行：
  - **合计**：当月用气量/用电量各列 SUM；发电率 = 合计用电量 ÷ 合计用气量（重算，IFERROR→0）。
  - **累计总合计**：自报表起始月至当前月**所有月合计相加**（如当前 8 月 = 6+7+8 月合计）；发电率按累计电量 ÷ 累计气量重算。**不**采用「末行读数−初始读数」口径（负值→0 场景下两者不等）。
  - **核对行**：期末读数−期初读数（井队电量×变比），源自原表手工核对习惯（10月 sheet 底部公式），与合计行交叉校验；正常月份两者一致，换表/读数倒挂（负值→0）时可能不等。
- **记录修改**：有按钮权限者弹窗编辑录入字段（读数、值班人、工况、井深、在发机组），计算列只读预览；保存后该月及其后受影响记录重算。
- 电站（井队）配置页（管理员）：维护 §2.1 全部配置项。

### 2.6 导出 Excel

- PC 报表页一键导出当月报表（含累计总合计行），由**后端生成**，版式还原需求模板：
  - 标题行「XXXX年燃气发电服务报表」、头信息行（井队号+队；井别/井类型/设计井深/井位号留空；井队电表变比）
  - 双行合并表头，撬电表列动态
  - 明细、合计行、累计总合计行、核对行

### 2.7 权限矩阵

| 角色 | 电站配置（变比/初始值/撬/机组） | 抄表录入 | 修改记录 | 报表查看/导出 |
|---|---|---|---|---|
| 管理员/专人 | ✅ | ✅ | ✅ | ✅ |
| 现场填报人 | ❌ 只读 | ✅ | ✅（按按钮权限） | ✅ |
| PC 普通用户 | ❌ | — | 按按钮权限 | 按菜单权限 |

### 2.8 菜单关联关系（不做菜单原型，仅明确挂靠关系）

- **PC 端**：复用平台现有「电站（井队）」菜单节点，其下挂两个页面——「燃气发电服务报表」（查看/导出/修改）与「电站配置」（管理员）；**报表查询模块下新增「发电服务报表」（管理员菜单权限）**；App **工作台新增「抄表」**入口。

## 3. 计算口径（与 Excel 完全同步）

### 3.1 列结构（动态）

表头信息行：`井队：{井队号}队 | 井别：{井别} | 井类型：{井类型} | 设计井深：{设计井深}米 | 井位号：{井位号} | 井队电表变比：{变比}`（井别/井类型/设计井深/井位号取自电站信息，随配置更新）

> 列名展示支持**自定义表头**（§2.4）：接口返回 default_name + custom_name，前端优先展示自定义名；导出同步使用自定义名。

| 列 | 名称 | 单位 | 来源 |
|---|---|---|---|
| 1~3 | 序号、日期、时间 | — | 系统预生成 |
| 4 | 值班人 | — | 📱 录入 |
| 5 | 工况 | — | 📱 字典 |
| 6 | 井深 | m | 📱 录入 |
| 7~6+N | **撬电表读数（×N，动态）** | KW·h | 📱 录入 |
| 7+N | 流量计（沃达）读数 | m³N | 📱 录入 |
| 8+N | 电表（井队）读数 | KW·h | 📱 录入 |
| 9+N | 流量计（井队）读数 | m³N | 📱 录入 |
| — | （沃达）用气量 | m³N | 计算：沃达流量计本行−上行，负值→0 |
| — | （沃达）累计用气量 | m³N | 计算：本行读数−初始值 |
| — | （沃达）用电量 | KW·h | 计算：**Σ各撬电表差值**，单项负值→0 |
| — | （沃达）累计用电量 | KW·h | 计算：Σ(撬读数−初始值) |
| — | （井队）用气量 | m³N | 计算：井队流量计差值，负值→0 |
| — | （井队）累计用气量 | m³N | 计算：本行读数−初始值 |
| — | （井队）用电量 | KW·h | 计算：井队电表差值×变比，负值→0 |
| — | （井队）累计用电量 | KW·h | 计算：(本行读数−初始值)×变比 |
| — | （沃达）发电率 | kW·h/m³N | IFERROR(沃达用电量÷用气量, 0)，无用气时展示 — |
| — | （井队）发电率 | kW·h/m³N | IFERROR(井队用电量÷用气量, 0)，无用气时展示 — |
| 末 | 备注 | — | 📱 在发机组选择自动拼接 |

### 3.2 基线与差值

- Excel 中首条有效读数行即基线（其后行差值/累计公式硬编码基线常量）；系统中基线**前置为管理员录入的初始值**，首条移动端记录即产生差值 = 读数 − 基线。
- Excel 中沃达累计用气量曾硬编码 `12.82` 而首录实际 `12.823`（手工误差）；系统以管理员录入初始值为唯一基准，消除该误差。
- 变比为每块电表的基准值属性（默认 1），当前仅电表（井队）配置 3960，仅乘在井队电表相关列；撬电表、两块流量计变比为 1（不缩放）。

### 3.3 合计与累计总合计

- 合计 = 当月各计算列 SUM；发电率按合计电量 ÷ 合计气量重算。
- 累计总合计 = 起始月至当前月各月合计相加；发电率同样重算。
- 核对行 = 期末读数 − 期初读数（井队电量 ×变比），与合计行交叉校验；正常月份两者一致，发生换表/读数倒挂（负值→0）时可能不等，不等即为异常排查信号。

### 3.4 计算落库与重算

- 保存/修改记录时，服务端按公式链计算 M~V 类列并**落库快照**（含受连锁影响的同月后续记录一并重算）。
- 历史月数据不因变比/初始值后续调整而回溯变化（与 Excel 各月硬编码基线的行为一致）。
- 查询与导出直接消费快照，免实时全量重算。

## 4. 数据模型草案（后端）

| 表 | 关键字段 |
|---|---|
| 电站表 `voda_station` | id、station_code（井队号）、station_name、**well_type（井别）、well_category（井类型）、design_depth（设计井深米）、well_location（井位号）**、start_month（报表起始月）、**shifts（班次时间 JSON，默认 ["08:00","14:00","20:00"]）**、status、租户/审计字段 |
| 电表配置表 `voda_station_meter` | id、station_id、meter_type（1撬电表/2沃达流量计/3井队电表/4井队流量计）、name、initial_reading（初始读数）、**ratio（变比，默认 1；井队电表=3960）**、sort |
| 抄表记录表 `voda_reading_record` | id、station_id、record_date、shift（**班次时间点，取自电站 shifts 配置**，如 "08:00"）、duty_person（自动取当前登录人）、condition（字典值）、well_depth、meter_readings（JSON：meterId→读数）、selected_unit_ids（JSON，引用平台机组设备）、remark（拼接快照）、computed（JSON 计算快照）、**modifier_id / modifier_name / modify_time（修改人、修改时间审计）**、租户/审计字段 |
| 表头自定义表 `voda_report_header` | id、station_id、field_key（列字段名）、default_name（原名称）、custom_name（自定义名称）、update_by / update_time；仅存差异项，未配置的列用默认名 |

> 机组不建表：在发机组多选与备注拼接直接引用**平台电站下的机组设备数据**，报表域不维护机组清单。

契约红线：`meter_readings`/`computed` 等 JSON 结构**只增不改**，向下兼容历史存量；严禁在请求路径硬编码 `/admin-api`。

| `GET/PUT /voda/report/header-custom?stationId` | 查询/保存自定义表头（原名称→自定义名称，支持恢复默认） | `voda:report:header`（管理员） |

字典：`voda_work_condition`（燃气发电工况，系统数据字典维护）。

## 6. 非功能约束

1. **i18n**：严禁硬编码中文文案；PC `src/locales/zh-CN.ts` 与 `en.ts` 同步配平；App `common/locales/` 中英键集合完全配平；交付前正则自查。
2. **App 端（Vue2/uni-app）红线**：模板禁 `?.`/`??`（buble 编译崩溃）；SCSS 花括号严格配平、深度选择器用 `::v-deep`；交互 `@tap`；主容器 100% 高度禁 `100vh`；不嵌套多层 `scroll-view`。
