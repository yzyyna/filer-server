关联原型 库存使用报表-V2.html

功能路径：数据查询 → 报表查询 → 资产库存使用表

1. 功能说明

资产库存使用表是「数据查询 - 报表查询」下的库存台账查询页，用于按条件查询电站现场物资（消耗品 / 备件）的出入库记录，通过「在库」与「已出库」两大 Tab 页签快速分流查询，查看库存与消耗的数量、金额，并导出结果。

本页只做查询、统计、导出；台账的录入与修改在其他业务环节完成，本页数据只读。

2. 页面结构

自上而下包含五大功能区域：

区域 设计规范与内容（对齐 iot-web）
页面标题 顶部标题「资产库存使用表」，左侧展示面包屑路径，右侧展示数据更新时间戳
筛选条件区 采用 Element Plus 行内表单样式：5 个筛选条件（仓库、名称、类别、所属电站、时间范围） + 右侧 重置 / 查询 / 导出 按钮组；时间标签随当前 Tab 动态联动为「入库时间」或「出库时间」
Tab 页签筛选区 Element Plus 下划线风格页签：「在库」与「已出库」两大 Tab，右侧展示当前状态下的记录总数 Badge 徽标。库存状态由 Tab 页签唯一承载，明细表中不再单设「库存状态」列
统计栏 在库严格显示在库（在库数量、在库总金额）；已出库严格显示已出库（出库数量、出库总金额），避免跨状态混杂
明细表格 10 列；序号为正常单行自增编号（一行一个序号，不合并跨行）；最后一列随 Tab 动态切换为「最新入库时间」或「出库时间」
分页组件 采用 iot-web 标准的 el-pagination（共 x 条、每页条数下拉、页码方块翻页、前往第 x 页），右浮动布局

3. 筛选条件

条件 控件类型 默认值 说明
仓库 Element Select 全部 选项取自系统现有仓库列表
名称 Element Select 全部 物资实际名称
类别 Element Select 全部 资产 / 备件 / 油品 / 耗材
所属电站 Element Select 全部 所属电站编号
时间范围 Element DateRange (精确到分) 当月 1 日 00:00 ~ 当天 23:59 在「在库」Tab 下标签显示为「入库时间」，筛选物资最新入库时间
在「已出库」Tab 下标签显示为「出库时间」，筛选物资实际出库时间
重要交互说明：筛选区的「库存状态」已升级为表格上方的「在库」/「已出库」Tab 页签，状态语义由 Tab 唯一承载，明细表中不再重复展示「库存状态」列。
  • 点击「查询」或在表单中回车立即触发查询。
  • 开始时间晚于结束时间时不执行查询，弹出 Element Plus Warning 提示「开始时间不能晚于结束时间」。
  • 点击「重置」按钮恢复所有下拉为「全部」，时间恢复当月默认区间，并切回第 1 页。

4. 统计栏

统计原则：在库显示在库，已出库显示已出库。严格按当前 Tab 隔离统计，杜绝跨状态混杂展示。

当前页签（Tab） 展示指标项 计算口径 样式规范
在库 1. 在库数量
2. 在库总金额 		• 在库数量：当前筛选条件下状态为「在库」的数量之和
• 在库总金额：在库记录的 数量 × 单价(元) 之和，保留 2 位小数 		在库数量采用 Element 主色蓝（#409eff）高亮加粗展示；右侧附带提示「当前统计口径：在库物资数量与金额合计」
已出库 1. 出库数量
2. 出库总金额 		• 出库数量：当前筛选条件下状态为「已出库」的数量之和
• 出库总金额：已出库记录的 数量 × 单价(元) 之和，保留 2 位小数 		出库数量采用 Element 暖色橙（#e6a23c）高亮加粗展示；右侧附带提示「当前统计口径：已出库物资数量与金额合计」

5. 明细表

5.1 列定义（10 列）

列名 字段说明 交互与展示规范
序号 自然自增行号 正常单行一行一个序号（1, 2, 3...），不再做跨行单元格合并
类别 资产 / 备件 / 油品 / 耗材 居中对齐
名称 物资名称 居中对齐，加粗，鼠标悬停 Tooltip
所属电站 电站编号，如 50123-1# 居中对齐，悬停显示层级完整路径
规格型号 物资规格描述 居中对齐
编号 物资资产编号 等宽字体展示
数量 单据数量 整数展示，等宽字体
单位 吨 / 桶 / 只 / 条 等 居中对齐
单价(元) 含税单价 右对齐，保留 2 位小数
时间列（动态） 根据当前 Tab 动态展示 「在库」Tab：列名为「最新入库时间」（提示：在库物资的最新入库时间）
「已出库」Tab：列名为「出库时间」（提示：物资出库操作时间）
说明：原 V1 / V2 初版的「库存状态」列已删除——当前所在 Tab（在库 / 已出库）即唯一标识本页全部记录的状态，页面内再重复展示一列同值状态属于信息冗余。

5.2 记录识别规则（取数口径）

  • 识别字段：类别、所属电站、库存状态、单价(元)。
  • 识别字段中任一项不同，即为一条独立记录。
  • 同名物资若电站、编号或单价不同，视为独立记录，各自独立占一行并分配自然序号。
  • 后台分别按「在库」和「已出库」两个集合查询，前端 Tab 进行无缝分流展示。

6. 操作

操作项 交互行为与系统响应
查询 按当前选定条件检索列表并重算统计栏，页码恢复到第 1 页
重置 所有筛选条件恢复默认，时间恢复当月 1 日至当天，页码回到第 1 页
导出 导出当前选定 Tab 且符合筛选条件的全量数据（非仅当前页）；CSV 格式、UTF-8 BOM 编码（Excel 打开不乱码）；含与页面一致的 10 列表头（不含「库存状态」列）；文件名如 资产库存使用表_在库_20261110.csv
Tab 切换 点击「在库」或「已出库」，立即切换数据集、切换表头时间列名称、切换统计栏展示指标（在库数量/金额 vs 出库数量/金额）、同步重置页码为 1

7. 边界与待确认

7.1 边界

  • 筛选无结果：显示 Element 风格空态缺省图（📦 暂无符合条件的库存记录）、分页总数显示「共 0 条」。
  • 横向滚动与固定列：表格支持横向滚动，表头纵向粘性吸顶；打印模式下自适应隐藏筛选区。

7.2 待确认

  • 总数量与总金额跨单位（吨 / 桶 / 只 / 条）合计是否需要进一步按单位类型细分汇总。
  • 历史出入库流水是否支持追溯到原始出库单据号或领用人工号。

自检

  • 功能说明清晰讲清了定位与边界
  • 筛选组全面对齐 iot-web（Element Plus）规范
  • 新增在库/已出库 Tab 筛选，入出库时间列动态联动
  • 统计栏严格分流：在库显示在库数量/金额，已出库显示出库数量/金额
  • 已删除「库存状态」列，状态语义由 Tab 唯一承载
  • 序号恢复正常单行自然递增，取消跨行合并
  • 分页组件全面对齐 iot-web（Element Plus）规范
