01 系统架构与业务流转设计

服务到期提醒功能旨在为发电机组运维人员提供“事前主动触达 → 列表聚合管控 → 详情一键拨号续期/监控联动”的完整业务闭环。系统充分利用 uni-app 跨端能力，在 APP 启动与唤醒时进行静默校验与本地通知下发，同时在消息中心与详情页提供原生级交互体验。

STEP 01

启动静默探测

App 启动或切到前台，检查登录态后静默请求临期接口 GET /api/services/expiring?days=30。

STEP 02

频控与通知下发

根据最后提醒时间戳进行防骚扰判断，调用 plus.push.createMessage 弹出系统状态栏通知。

STEP 03

消息中心聚合

「消息中心」第 4 个 Tab 展示服务到期列表，≤7天卡片红标置顶，支持下拉刷新与分页加载。

STEP 04

详情续期与监控

点击进入详情页，Hero 区域倒计时预警，一键呼叫 400 运维热线，行内直达机组实时监控。

3.3 本地通知调度与防骚扰频控管理器 (common/serviceExpireManager.js)

负责从后台拉取临期数据、计算剩余时间、根据防骚扰策略筛选需提醒项，并调用底层 plus.push 生成原生通知。

频控算法与逻辑实现：

/**
 * common/serviceExpireManager.js
 * 服务到期提醒核心管理器
 */
import { timeFormatFun } from '@/common/utils'

const STORAGE_KEY_LOG = 'SERVICE_EXPIRE_PUSH_LOG'
const HOTLINE_DEFAULT = '400-888-0808'

export default {
  /**
   * APP 冷启动/热启动时入口探测
   */
  async checkAndNotify(vueInstance) {
    // 检查登录状态
    if (!vueInstance.vuex_sessionId || !vueInstance.vuex_user) return

    try {
      // 1. 调用接口获取 30 天内临期服务
      const res = await vueInstance.$u.api.message.getExpiringServices({ days: 30 })
      if (!res || res.Code !== 1 || !res.Data || !res.Data.List) return

      const list = res.Data.List.map(item => this.formatServiceItem(item))
      
      // 更新 Vuex 状态供全局消息中心与角标使用
      vueInstance.$u.vuex('vuex_expiring_services', list)

      // #ifdef APP-PLUS
      // 2. 本地系统通知生成与防骚扰校验
      this.dispatchLocalPush(list)
      // #endif
    } catch (e) {
      console.error('[ServiceExpireManager] 探测到期服务失败:', e)
    }
  },

  /**
   * 格式化与时间换算规则
   */
  formatServiceItem(raw) {
    const now = Date.now()
    const expireTime = new Date(raw.ExpireDate.replace(/-/g, '/')).getTime()
    const diffMs = expireTime - now
    const diffHours = diffMs / (1000 * 60 * 60)
    const diffDays = Math.floor(diffHours / 24)

    let remainText = ''
    let isEmergency = false

    if (diffMs <= 0) {
      remainText = '已到期'
      isEmergency = true
    } else if (diffDays >= 1) {
      remainText = `${diffDays} 天后到期`
      if (diffDays <= 7) isEmergency = true
    } else if (diffHours >= 1) {
      const h = Math.floor(diffHours)
      const m = Math.floor((diffMs % (1000 * 60 * 60)) / (1000 * 60))
      remainText = `${h} 小时 ${m} 分后到期`
      isEmergency = true
    } else {
      const m = Math.max(1, Math.floor(diffMs / (1000 * 60)))
      remainText = `${m} 分钟后到期`
      isEmergency = true
    }

    return {
      serviceId: raw.ServiceId || raw.Id,
      unitCode: raw.UnitCode || raw.GeneratorSetNo,
      stationName: raw.StationName || raw.ProjectName,
      generatorSetId: raw.GeneratorSetId,
      cloudCatCode: raw.CloudCatCode || raw.CollectorToken,
      location: raw.Location || raw.Address || '未知位置',
      gensetStatus: raw.GensetStatus || 1,
      expireDate: raw.ExpireDate,
      remainSeconds: Math.max(0, Math.floor(diffMs / 1000)),
      remainText,
      isEmergency,
      serviceTypes: this.parseServiceTypes(raw.ServiceTypes),
      hotline: raw.Hotline || HOTLINE_DEFAULT
    }
  },

  /**
   * 调度本地系统通知
   */
  dispatchLocalPush(list) {
    const pushLogs = uni.getStorageSync(STORAGE_KEY_LOG) || {}
    const now = Date.now()
    const todayStr = new Date().toISOString().slice(0, 10)

    list.forEach(item => {
      if (item.remainSeconds <= 0) return // 已到期项视业务需要决定是否重复弹

      const lastLog = pushLogs[item.serviceId]
      let shouldPush = false

      if (!lastLog) {
        shouldPush = true
      } else {
        const lastPushTime = lastLog.time
        const lastDateStr = lastLog.date

        if (item.remainSeconds <= 86400) {
          // <= 1天：每小时最多 1 次
          if (now - lastPushTime >= 3600 * 1000) shouldPush = true
        } else {
          // > 1天 且 <= 30天：每天最多 1 次
          if (lastDateStr !== todayStr) shouldPush = true
        }
      }

      if (shouldPush) {
        const primaryService = item.serviceTypes[0] ? item.serviceTypes[0].name : '云监控服务'
        const content = `机组 ${item.unitCode}（${item.stationName}）的${primaryService}将在 ${item.remainText}后到期，为避免数据通信中断和丢失，失去监控权，请及时续期。`
        
        plus.push.createMessage(content, JSON.stringify({
          type: 'service_expire',
          serviceId: item.serviceId,
          generatorSetId: item.generatorSetId,
          unitCode: item.unitCode
        }), {
          title: '服务到期提醒',
          cover: false
        })

        // 更新推送日志
        pushLogs[item.serviceId] = { time: now, date: todayStr }
      }
    })

    uni.setStorageSync(STORAGE_KEY_LOG, pushLogs)
  }
}

4.2 服务类型字典枚举约定

服务枚举 Key 中文名称 英文名称 (i18n) 业务影响说明
communication 通信服务 Communication Service 到期导致机组掉线，无法采集遥测遥信数据，失去监控权
history_storage 历史数据存储 Historical Data Storage 到期导致新产生的数据无法持久化归档
remote_param 远程调参 Remote Parameter Tuning 到期无法远程配置控制器参数
remote_diag 远程故障诊断与处理 Remote Fault Diagnosis 到期无法进行专家系统云端故障辅助诊断
maintain_mgmt 维保提醒与管理 Maintenance Management 到期无法接收智能保养工单派发提醒
video_stream 视频流服务 Video Streaming 到期无法查看现场摄像头实时推流（按需扩展）

05 异常边界与多端兼容方案

1. 跨平台兼容策略

App 平台：使用 plus.push 与 plus.device.dial；
H5 外壳：条件编译屏蔽 plus 调用，降级为 uni.makePhoneCall 与页面内通知。

2. 离线/网络断开

接口失败时静默捕获，读取上次已缓存的 vuex_expiring_services 确保列表可读，不弹阻断性错误弹窗。

3. 状态联动与传参

进入机组监控前，自动拉取机组详情并更新 vuex_gensetInfo，避免进入监控页后因缺少机组缓存报错。
