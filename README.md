# filer-server

轻量级局域网文件共享服务器，零构建、极简依赖（Express 5 + multer 2），单命令即开即用。

---

## 核心特性

- 🚀 **零构建启动**：纯原生前端（HTML5 / CSS3 / ES2015+）+ 单文件后端，`npm start` 即用。
- 🔒 **访问安全认证**：支持基于 `AUTH_PASSWORD` 环境变量开启访问鉴权，7 天有效 Cookie Session，内置防爆破限速（429）。
- 📂 **目录层级浏览**：支持面包屑导航、子目录进入/返回、目录与文件分组排序。
- 📤 **多文件拖拽上传**：支持批量文件选择与拖拽上传，实时显示传输进度条，自动处理中文文件名与同名冲突。
- 👁️ **在线媒体预览**：支持图片、音视频、PDF、文本/代码文件内联预览。
- 📋 **一键复制链接**：支持一键复制下载链接与预览链接，便于团队协作与外部文档嵌入。
- 🌐 **多语言支持**：内置英文、中文、日文、韩文四语字典，支持系统语言自动检测与本地持久化切换。
- 🛡️ **安全防护**：后端防路径穿越（Directory Traversal）、禁止主目录根路径上传。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

#### 模式 A：开放免密模式（默认）
```bash
npm start
# 或 node server.js
```

#### 模式 B：密码认证模式（推荐团队环境开启）
```bash
AUTH_PASSWORD=你的访问密码 npm start
```

启动成功后，控制台将输出局域网访问地址：
```text
文件服务器已启动：
- 本机访问:   http://localhost:8888
- 局域网访问: http://192.168.x.x:8888
- 访问认证:   已启用 (7天有效 Cookie Session)
```

## 环境变量说明

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `8888` | 服务监听端口 |
| `AUTH_PASSWORD` | *(空)* | 访问认证密码。若不设置则不启用鉴权（免密模式） |
| `AUTH_SECRET` | *(自动基于密码生成)* | HMAC 签名密钥，可自定义固定密钥 |

## API 列表

| 接口 | 方法 | 权限 | 说明 |
|---|---|---|---|
| `/api/auth/status` | `GET` | 公开 | 查询当前服务鉴权启用状态与会话认证状态 |
| `/api/login` | `POST` | 公开 | 密码登录（5 分钟内最多尝试 5 次） |
| `/api/logout` | `POST` | 公开 | 退出登录并清除会话 Cookie |
| `/api/files` | `GET` | 需认证 | 获取当前目录的文件与文件夹列表 |
| `/api/upload` | `POST` | 需认证 | 上传文件（`dir` 指定目标子目录，`files` 携带多文件） |
| `/api/download` | `GET` | 需认证 | 下载指定路径的文件 |
| `/api/preview` | `GET` | 需认证 | 在线预览指定路径的文件（`inline` 展示） |
| `/api/delete` | `DELETE` | 需认证 | 删除指定路径的文件 |
